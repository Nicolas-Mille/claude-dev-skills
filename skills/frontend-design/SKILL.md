# Frontend Design

Design for a serious B2B product, not an AI demo.

Prioritize:
- clear information hierarchy
- scannable financial numbers
- compact but readable layouts
- obvious primary actions
- visible pending vs confirmed state
- visible uncertainty for AI suggestions
- drill-down instead of overloaded dashboards
- useful empty/loading/error states
- keyboard-friendly repetitive workflows where appropriate

Avoid:
- decorative gradients without purpose
- excessive cards
- giant marketing headings inside the application
- fake analytics
- gratuitous animation
- AI sparkle aesthetics
- hiding critical financial context behind hover-only interactions

Preserve functionality and data clarity before visual novelty.
